NEEDS `!bset loadallunits = 1` AND LOOTBOXES ENABLED

Replaces lootboxes with Raptor Hatcheries. They can be captured like normal lootboxes!
- Each hatchery has a "Raptor Constructor" that can build the next tier of factory.
  - Hatcheries generated by Lootbox spawns generate metal and energy, and also have increased buildpower to super produce units.
- Higher tiers = Higher maturity!
- Separate air factory for flying raptors.
- Scavengers will use lootboxes to build raptors if not captured by players.

Lootbox Replacements:
- Bronze: Juvenille Hatchery
- Silver: Common Hatchery
- Gold: Apex Hatchery
- Platinum: Royal Hatchery
