NEEDS LOADALLUNITS

Replaces lootboxes with Raptor Factories. They can be captured like normal lootboxes!
- Each factory has a "Raptor Constructor" that can build the next tier of factory.
- Higher tiers = Higher maturity!
- Separate air factory for flying raptors.
- Scavengers will use lootboxes to build raptors if not captured by players.
